# Project Roadmap - Blockchain Supply Chain System

## Milestones

### Milestone 1: Core Ledger and Backend Hub (The Foundation)
1. Phase 1: Solidity Smart Contract for Product Tracking.
2. Phase 2: Java/Spring Boot Backend Skeleton and MongoDB Setup.
3. Phase 3: Basic Product Registration API.

### Milestone 2: Event-Driven Synchronization (The Bridge)
1. Phase 4: Kafka Integration and On-Chain Event Listening.
2. Phase 5: Off-Chain Metadata Storage and Retrieval Logic.

### Milestone 3: Real-Time Dashboards and Verification (The Interface)
1. Phase 6: Manufacturer and Stakeholder Dashboards (React).
2. Phase 7: Consumer QR Code Verification Portal (React).
3. Phase 8: End-to-End Integration and Testing.

## Future Phases
- [ ] Integration with External IoT Sensors.
